## 工程对齐（现行）

顶栏已按上表：标题 104²、分数 93×92、按钮 93×28 `#ed995b` 与分数对齐。  
棋盘宽由 `boardScale` 默认 1.09 接近 358；`boardY` 默认 20 往下。  
入口：黄块切模式，设置开手感。原版「排行榜」在本工程是「设置」。
