# SFX sources

现行：UI SFX Minimal（CC0，https://uisfx.com），`public/sfx/v2/`。合/滑=`snap` 按档变调；UI=`press`；回弹=`invalid-drop`。

| 槽 | 角色 |
|----|------|
| slide | 海绵/滚筒涂抹，能量 < ~700 Hz |
| merge | 涂满：圆 pop，不变调 |
| spawn | 更轻的 pop（玩法未接线） |
| nudge | 更短、更暗的抹 |
| ui | 极短湿 tap |
| over | 两个下行 pop |
| win | 两个略亮的 pop |
